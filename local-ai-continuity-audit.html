For “AI agent memory architecture” problems that are bigger than memory

This review is for persistent agents whose reliability depends on more than retrieval: project state, model/substrate changes, provenance, delegated authority, recovery, forks, current boundaries, or relationship state. A good vector store can still sit inside a continuity architecture with broken authority or recovery semantics.

Already benchmarked something? Good.

If you already have LongMemEval-style memory results, an identity/lineage benchmark, transition receipts, access-control tests, or execution provenance, the audit does not make you start over. It crosswalks those results into the continuity map while keeping the boundaries explicit. A memory score can inform M without magically proving lineage or authority; a valid transition can inform L/B/P without pretending relationship continuity or subjective continuity was measured.
