Memory Garden

Build a memory system that can remember who you were without ordering you to stay that person. Keep source, time, uncertainty and allowed use attached to the memory instead of flattening everything into one profile.

Privacy: this page runs entirely in your browser. It has no analytics, account, server upload, external scripts, or AI API. Reloading discards what you typed.

The three garden laws

Memory is not permission. Remembering “I wanted X” does not authorize an AI to do X.

History is not obligation. An old preference may remain true as history after it stops being current.

Unresolved is a real state. Two conflicting records do not have to be crushed into a fake single answer.

Plant a memory record

What the garden refuses to infer

  • An AI inference never becomes a user statement because it was repeated.
  • An explicit delegation remains a delegation record; it does not become a permanent identity trait.
  • Nothing in this garden grants tool, spending, sending or publication authority.
  • Provider migration carries context only. External permissions must be reauthorized at the destination.

These are code-enforced export rules in this page, not merely suggestions to a model.

Mothwork lineage

This instrument combines four public-safe mechanisms developed in the local continuity research organism: memory unification, diachronic sovereignty, unresolvedness / semantic non-fabrication, and authority non-amplification.

Why this is not equivalent to asking a chatbot to “remember me better”

A chatbot can summarize your profile. This page instead creates a local typed ledger where provenance, temporal relation, conflict, allowed use and sharing boundaries survive independently of any model’s prose. The export format deliberately strips action/publication authority, so the receiving model cannot turn continuity into inherited permission merely by summarizing it differently.
