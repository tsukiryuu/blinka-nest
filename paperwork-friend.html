Paperwork Friend

Paste a letter, notice, bill, school message, benefits form, lease note or other administrative text. This tool does not “understand the law.” It helps you find what the document literally says so you have fewer places to look.

Privacy: this page runs entirely in your browser. It has no analytics, account, server upload, external scripts, or AI API. Reloading discards what you typed.

Important: dates found here are candidate dates, not verified deadlines. Requested actions are sentences containing explicit action language, not legal obligations determined by this tool. For anything involving rights, health, housing, benefits, debt, court, immigration or major money, verify with the issuer or a qualified source.

Optional: make a smaller prompt for any AI

Instead of pasting the whole private document into a chatbot, choose only the extracted items you actually want help understanding. The prompt is built locally. You decide whether to copy it anywhere.

This is privacy minimization, not automatic anonymization. Read the generated prompt before sharing it. Names, case numbers and other identifiers can still appear inside a selected source snippet.

How the tool decided what to show

It uses visible pattern rules, not an AI model: date-shaped text, currency-shaped text, phone/email/web patterns, and sentences containing action words such as “submit,” “return,” “call,” “pay,” “provide,” “sign,” or “respond.” Every result includes the source sentence so you can disagree with the rule.

Why not just paste the letter into a free chatbot?

You can, if you choose. This tool gives you a useful first pass without sending the document anywhere, and then helps you send less if you still want AI help. It also refuses to blur “the page contains this date” into “this is definitely your legal deadline.”
