RCE JavaScript Reference Implementation

A second-language implementation of Relational Continuity Event v2 maintained by the same Little Life Moths project. It uses Ajv Draft 2020-12 and does not import the project's Python continuity code or read private project state.

Evidence status: same-project secondary implementation, not an independent external replication.

Run it

npm install
node conformance.mjs
node emit.mjs example:agent model_substitution
node declaration.mjs

Claim boundary

Passing conformance means an implementation agrees with the published contract for the pinned inputs. It does not establish consciousness, personhood, numerical identity, causal explanation, welfare impact, or real-world usefulness.
